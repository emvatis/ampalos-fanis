# Άμπαλος Φάνης - .md Creator 📝

This project is a simple web application that allows you to create `.md` (Markdown) files through a user-friendly form. 

## Features ✨

*   **Text Input:** A textarea for entering the main content of your Markdown file.
*   **Title Input:** A text field for specifying the title of your Markdown file.
*   **Date Input:** A date picker for selecting the date associated with the content.
*   **Image Upload:** An option to upload an image to be included in the Markdown file.
*   **Link Information:** Fields for adding a newspaper name and URL related to the content.
*   **Tags Input:** A text field for adding comma-separated tags to categorize the content.
*   **Automatic File Naming:** Generates a `.md` file name based on the date and title.
*   **Image Naming Suggestion:** Recommends a name for the uploaded image based on the date and title.

## Usage 🚀

1.  Fill out the form with the necessary information.
2.  Click the "Δημιουργία αρχείου" (Create File) button.
3.  A `.md` file will be generated and downloaded to your computer.
4.  If you uploaded an image, rename it to the suggested name and place it in the `/articles/images/` directory.
